# Ответы на вопросы задания

1. **Почему для обложки вы использовали растровый файл, а для значка — SVG?**
Растровый файл используется для обложки, потому что он содержит сложную цифровую иллюстрацию с множеством мелких деталей и плавными переходами цветов. SVG используется для значка, так как это простая геометрическая фигура, которая должна четко масштабироваться до любых размеров без потери качества и появления пикселей.

2. **Какую цветовую пару вы выбрали? Как расположены эти цвета на учебном цветовом круге?**
Выбрана пара: глубокий тёмно-синий (`#0B132B`) для фона значка и золотисто-желтый (`#FFD700`) для полумесяца. На учебном цветовом круге эти цвета являются комплиментарными (контрастными) и расположены строго напротив друг друга.

3. **Как записан цвет вашей кнопки в HEX и в RGB или HSL? Какую модель используют при подготовке полноцветной печати?**
* Запись цвета кнопки:
  * HEX: `#0B132B`
  * RGB: `rgb(11, 19, 43)`
  * HSL: `hsl(225, 59%, 11%)`
* Для подготовки полноцветной печати используют цветовую модель **CMYK**. Для цифровых экранов используются модели RGB, HEX и HSL.
